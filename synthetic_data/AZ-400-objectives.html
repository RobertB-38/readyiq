AZ-400: Designing and Implementing Microsoft DevOps Solutions — Skills Measured

SYNTHETIC DEMO DOCUMENT — for ReadyIQ hackathon demo only. Not official Microsoft content.

Domain 1: Configure processes and communications (10-15%)

Configure activity traceability and flow of work; configure collaboration and communication (wikis, dashboards, Azure Boards integration). A ready candidate can wire work items to commits and releases.

Domain 2: Design and implement source control (15-20%)

Design and implement branching strategies, configure and manage repositories, integrate GitHub repos with Azure Pipelines, manage large files and repository scale. A ready candidate can defend a trunk-based vs GitFlow choice.

Domain 3: Design and implement build and release pipelines (40-45%)

Design and implement CI/CD with Azure Pipelines and GitHub Actions; manage pipeline tasks, templates, and YAML; implement multi-stage pipelines, deployment gates, and approvals; manage secrets, secure files, and service connections; implement infrastructure as code (Bicep/ARM/Terraform) in pipelines. This is the largest and most important domain. A ready candidate can author a multi-stage YAML pipeline with approval gates from memory.

Domain 4: Develop a security and compliance plan (10-15%)

Implement pipeline security, scan for vulnerabilities and secrets, manage dependencies and licensing. A ready candidate can add dependency scanning to a pipeline.

Domain 5: Implement an instrumentation strategy (10-15%)

Configure monitoring, integrate logging and telemetry, implement alerting and feedback loops. A ready candidate can define an SLA-based alert.

Readiness guidance

Because build/release pipelines is 40-45% of the exam, a candidate scoring below 60% in that single domain should be considered NOT READY regardless of other scores. Recommended overall: 75%+ across all domains and 25+ hours of pipeline-focused practice.
