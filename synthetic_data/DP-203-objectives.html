DP-203: Data Engineering on Microsoft Azure — Skills Measured

SYNTHETIC DEMO DOCUMENT — for ReadyIQ hackathon demo only. Not official Microsoft content.

Domain 1: Design and implement data storage (15-20%)

Design and implement a data storage structure and partition strategy; design and implement the serving/analytical layer with Azure Synapse and Data Lake. A ready candidate can choose a partitioning and file-format strategy for a lake.

Domain 2: Design and develop data processing (40-45%)

Ingest and transform data with Azure Synapse, Data Factory, and Spark; design and develop batch and stream processing solutions; handle schema drift, late-arriving data, and windowed aggregates. This is the largest domain. A ready candidate can build a Spark batch transform and a structured streaming job.

Domain 3: Design and implement data security (10-15%)

Implement data masking, encryption, row-level and column-level security, and manage access. A ready candidate can apply dynamic data masking.

Domain 4: Monitor and optimize data storage and data processing (10-15%)

Monitor pipelines, optimize and troubleshoot data processing, tune queries and partitions. A ready candidate can diagnose a skewed Spark job.

Readiness guidance

Data processing (40-45%) is the decisive domain. Recommended: 75%+ overall, 70%+ minimum on data processing, and 20+ hours of hands-on Spark/Synapse practice. Borderline candidates (overall 70-74%) should be flagged as "almost ready" with one targeted focus area.
