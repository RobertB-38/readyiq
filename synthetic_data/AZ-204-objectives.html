AZ-204: Developing Solutions for Microsoft Azure — Skills Measured

SYNTHETIC DEMO DOCUMENT — for ReadyIQ hackathon demo only. Not official Microsoft content. No real candidate data.

Domain 1: Develop Azure compute solutions (25-30%)

Implement containerized solutions: create and manage container images, publish to Azure Container Registry, run containers in Azure Container Instances, deploy to Azure Container Apps. Implement Azure Functions: create and configure triggers and bindings, implement durable functions. A ready candidate can author an HTTP-triggered function and explain consumption vs premium plans.

Domain 2: Develop for Azure storage (15-20%)

Develop solutions that use Azure Cosmos DB: perform operations on containers and items, set consistency levels, implement partitioning. Develop solutions that use Azure Blob Storage: move items between containers, set and retrieve metadata, implement lifecycle policies. A ready candidate can choose a partition key and justify a consistency level.

Domain 3: Implement Azure security (20-25%)

Implement user authentication and authorization using the Microsoft identity platform, MSAL, and Microsoft Graph. Implement managed identities and Azure Key Vault for secrets. A ready candidate can explain the OAuth 2.0 authorization code flow and when to use a managed identity over a secret.

Domain 4: Monitor, troubleshoot, and optimize Azure solutions (15-20%)

Implement caching with Azure Cache for Redis and Azure CDN. Instrument solutions with Application Insights, configure metrics and alerts. A ready candidate can interpret an Application Insights trace and add a custom metric.

Domain 5: Connect to and consume Azure services and third-party services (15-20%)

Implement API Management. Develop event-based solutions with Event Grid and Event Hubs. Develop message-based solutions with Service Bus and Storage Queues. A ready candidate can choose between Service Bus and Event Grid for a given scenario.

Readiness guidance

Recommended: 75% or higher on practice assessments across ALL five domains, and at least 20 hours of hands-on study, before sitting the exam. A single weak domain below 60% is a strong signal the candidate is not yet ready.
